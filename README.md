# app GuiaMobile

> Aplicativo mobile de auxílio à locomoção para pessoas com deficiência 
> visual em ambientes indoor, com instruções guiadas por voz.

## 🎯 Sobre

Projeto de TCC voltado à acessibilidade: um app que guia pessoas com 
deficiência visual por rotas indoor pré-cadastradas, fornecendo 
instruções por voz nativa em cada etapa do trajeto.

## ✨ Funcionalidades

- Autenticação de usuário
- Consulta de rotas indoor previamente cadastradas
- Instruções de navegação por voz, nativas no app

## 🛠️ Tecnologias

- [React Native](https://reactnative.dev/)

## 🔗 Projeto relacionado

- [BackEnd_GuiaMobile](https://github.com/Geronilton/BackEnd_GuiaMobile) — API que fornece os dados de autenticação e rotas

## 🚀 Como rodar

\`\`\`bash
git clone https://github.com/Geronilton/app_GuiaMobile
cd app_GuiaMobile
npm install
npx react-native run-android  # ou run-ios
\`\`\`

> Requer o [BackEnd_GuiaMobile](https://github.com/Geronilton/BackEnd_GuiaMobile) rodando e configurado.

## 📌 Status

Projeto de TCC, protótipo funcional. As rotas precisam estar 
previamente cadastradas — ainda não há coleta ou mapeamento automático.
